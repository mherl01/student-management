# Student Management System

A Web-based Student Management System built with Node.js, Express, EJS, and MySQL.

## Features
- View Student List
- Add, Edit, and Delete Student records
- Search functionality by ID, name, or course
- Input validations and error handling

## Setup Instructions
1. Clone repository
2. Run `npm install`
3. Configure database details in `.env`
4. Start server: `node app.js`
